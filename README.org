* Overview

=bufferline.el= is an opinionated, minimalist buffer line for GNU Emacs built directly on top of the native =tab-line-mode= engine. It provides predictable FIFO tab indexing, dynamic theme color extraction, icon integration, buffer pinning, quick letter picking, and cyclic navigation.

* Requirements

- GNU Emacs >= 28.1
- =nerd-icons.el= (for filetype icon rendering)

* Installation

** Native =package-vc= (Emacs 30+)

#+begin_src emacs-lisp
  (use-package bufferline
    :vc (:url "https://github.com/szymonwilczek/bufferline.el")
    :config
    (global-bufferline-mode 1))
#+end_src

** Elpaca

#+begin_src emacs-lisp
  (use-package bufferline
    :ensure (:host github :repo "szymonwilczek/bufferline.el")
    :config
    (global-bufferline-mode 1))
#+end_src

** Straight.el

#+begin_src emacs-lisp
  (use-package bufferline
    :straight (:host github :repo "szymonwilczek/bufferline.el")
    :config
    (global-bufferline-mode 1))
#+end_src

** Local path

#+begin_src emacs-lisp
  (use-package bufferline
    :load-path "~/path/to/bufferline.el"
    :config
    (global-bufferline-mode 1))
#+end_src
