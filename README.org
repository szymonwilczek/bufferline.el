* Overview

=bufferline.el= is an opinionated, minimalist buffer line for GNU Emacs built directly on top of the native =tab-line-mode= engine. It provides predictable FIFO tab indexing, dynamic theme color extraction, icon integration, buffer pinning, quick letter picking, and cyclic navigation.

* Requirements

- GNU Emacs >= 28.1
- =nerd-icons.el= (for filetype icon rendering)

* Installation

** Native =package-vc= (Emacs 30+)

#+begin_src emacs-lisp
  (use-package bufferline
    :vc (:url "https://github.com/szymonwilczek/bufferline.el")
    :config
    (global-bufferline-mode 1))
#+end_src

** Interactive Commands

- =bufferline-next-tab=: Cycle forward to the next buffer in FIFO order.
- =bufferline-prev-tab=: Cycle backward to the previous buffer in FIFO order.
- =bufferline-close-tab=: Close the active buffer without altering window layout.
- =bufferline-toggle-pin=: Pin or unpin the current buffer to the beginning of the line.
- =bufferline-pick=: Jump to a visible buffer using single-letter tags.
- =bufferline-pick-close=: Close a specific buffer using single-letter tags.

** Keybindings

#+begin_src emacs-lisp
  (with-eval-after-load 'evil
    (define-key evil-normal-state-map (kbd "TAB") #'bufferline-next-tab)
    (define-key evil-normal-state-map (kbd "<tab>") #'bufferline-next-tab)
    (define-key evil-normal-state-map (kbd "<backtab>") #'bufferline-prev-tab)
    (define-key evil-normal-state-map (kbd "S-TAB") #'bufferline-prev-tab)
    (define-key evil-normal-state-map (kbd "<S-tab>") #'bufferline-prev-tab))

  (with-eval-after-load 'evil-keys
    (when (fboundp 'my-leader-def)
      (my-leader-def
        "b"  '(:ignore t :which-key "Buffers")
        "bp" '(bufferline-pick :which-key "Pick Buffer")
        "bd" '(bufferline-pick-close :which-key "Pick Close Buffer")
        "bc" '(bufferline-pick-close :which-key "Pick Close Buffer")
        "bP" '(bufferline-toggle-pin :which-key "Toggle Pin Buffer"))))
#+end_src
